# 线路组

一条转发规则可以配一个**线路组**：一个入口，后面挂几条**路径**，再选一种**调度策略**。路径可以经过中转（最多 5 跳），中转机上的中继由面板自动建、自动收；切换由入口机器上的 Agent 自己完成，不需要你盯着。

```text
转发：美国游戏线路
入口：0.0.0.0:10001
线路组
├─ A  主线路    入口 → HK01 → JP01 → US01:443
└─ B  备用线路  入口 → HK02 → SG01 → US01:443
策略：稳定优先（平时走 A，A 出问题自动换 B，A 恢复并稳定一阵再切回）
```

::: tip 线路组和「转发组」有什么不一样
- **线路组**（这一页）：挂在一条转发规则上，入口不变，换的是「从入口出去走哪条路」。切换由 Agent 在机器上完成，几秒内生效。
- **转发组的故障转移**：换的是「用户连进来的那个入口」，靠改 DNS 解析实现，需要配置 DDNS，见 [DDNS 和故障转移](./ddns.md)。入口机整台挂了才需要它。

只想「落地或中转挂了自动换一条路」，用线路组就够了。2.3.376 之前配的「主备线路」打开编辑框就是一个线路组（备用各是一条直连的路径），不用重配。
:::

## 三步开启 {#quick-start}

1. **新建或编辑一条转发规则**，照常选好线路、填好「目标地址」和「目标端口」。这个目标就是路径的默认落地。
2. 勾上表单里的 **「线路组」**。会给你两条路径：A 主线路（直连目标）和 B 备用 1。
3. 给 B 配路径：点 **「经过中转」** 从主机列表里挑中转（可以再加一跳），落地留空就是上面填的目标，要走别的落地就填 `地址:端口`。要更多路径点「添加路径」，最多 11 条。

模板默认是 **稳定优先**。路径下面有一句话复述「按现在这套设置，流量会怎么走」，例如：

> 平时都走 主线路；连续 3 次探测不通、持续 10 秒就换到下一条，切过去至少走 10 分钟，首选恢复并稳定 5 分钟后自动切回。切换只影响新连接，旧连接留在原线路。

确认这句话就是你想要的，点「保存」即可。其余设置按模板预填，收在「高级策略」里，一般不用动。

## 六种策略 {#modes}

策略是**模板**：选一种用法，切换保护的参数按推荐值预填；六种共用同一份路径清单，换策略不用重建路径。

| 模板 | 模式 | 它会怎么做 |
| --- | --- | --- |
| 稳定优先 | 自动故障切换 | 平时只走主线路，出问题自动换到下一条；主线路恢复并稳定一阵子再切回 |
| 早晚高峰 | 定时主备 | 按时段表（星期 + 时区）决定首选，比如晚高峰走 B；时段外回主线路；出问题照样往下切 |
| 人工掌控 | 手动主备 | 一直走你指定的那条，直到你换；它挂了才临时往下切，恢复后再回来 |
| 延迟优先 | 智能择优 | 按线路评分走最好的一条；分差够大、持续够久才换，不来回漂 |
| 晚高峰优化 | 混合策略 | 时段表给出首选，到点前先预热预检，预检不过就不切；时段外按评分走最好的一条 |
| 负载均衡 | 权重负载 | 新连接按权重分到各条路径，旧连接不动；哪条出问题就先跳过它 |

### 线路评分

延迟优先和晚高峰优化按**评分**挑路径：0–100，由延迟、丢包、抖动、建连成功率、可用率算出，90 起是「优」、80 起是「良」、其余「较差」。候选要比当前**高出 10 分以上、连续 3 分钟**才换（两个数在「高级策略 → 择优门槛」里改），避免两条差不多的线路来回漂。

### 计划切换预热

定时主备和混合策略到点前 **5 分钟**开始探测目标路径。混合策略下预检不过就**不切**，继续走当前这条，并在「最近切换」里记一条「计划切换未执行：备用线路 中转异常，继续使用 主线路」。

### 权重负载

按连接分配：新连接按权重分（每条路径旁边填权重，右边显示百分比），旧连接不动。也可以选轮流、随机、按访客固定（同一来源 IP 总走同一条，适合要保持登录的服务）。

## 它会怎么切（切换保护） {#how-it-switches}

拦的是网络抖一下引起的 A → B → A → B：

| 情况 | 默认 | 会发生什么 |
| --- | --- | --- |
| 探测失败一次 | — | 不切 |
| 连续失败满次数 | 3 次 | 标记这条路径异常 |
| 异常持续够久 | 10 秒 | 切到下一条能用的（Agent 每 5 秒探一次） |
| 用户新连接拨不通 | — | 算一次失败；连续满次数后当场改走下一条 |
| 坏掉的路径恢复了 | 稳定 5 分钟 | 才重新启用，避免时好时坏来回切 |
| 刚切过去 | 至少走 10 分钟 | 期间不按优先级切回；当前这条挂了不受它限制 |
| 首选恢复并稳定 | 开 | 自动切回首选（可以关掉） |

这些数都在「高级策略 → 切换保护」里改。

### 切换时旧连接怎么办

| 选项 | 行为 |
| --- | --- |
| 平滑切换（默认） | 旧连接留在原线路，新连接走新线路，基本无感 |
| 快速故障转移 | 线路挂了就断开它上面的旧连接，让客户端马上重连到新线路；计划和择优切换仍然平滑 |
| 强制切换 | 每次切换都断开旧连接，全部客户端立刻走新线路，可能重连 |

## 中转怎么探测 {#hops}

每条路径由入口 Agent 端到端探一次（连拨号地址，或你填的探测地址）；走中转的路径，**每台中转的 Agent 还会探它的下一跳**。某一跳连续 3 次不通，整条路径就标成「中转异常：JP01 → 落地」，入口机立刻拿到更新、换别的路径；恢复后自动解除。

中转机上的中继规则叫 `[线路组:规则名] 路径 N/M`，面板维护，不列在规则页、不算配额、不计流量；删掉路径或规则时一起收回。

## 能不能用 {#requirements}

线路组需要 GOST 来切换，所以：

| 规则类型 | 能不能用 |
| --- | --- |
| 隧道转发（GOST 隧道） | 可以，入口是隧道的出口机 |
| 端口转发（管理员） | 可以。勾上时，转发工具会自动换成 GOST |
| 端口转发（普通用户） | 选管理员开好的 GOST 端口转发可以；普通端口转发不行，界面上会给「改用隧道转发」按钮 |
| 转发组 | 可以配直连的路径，暂不支持经过中转 |
| 转发链 | 不可以 |
| 协议 | 只支持 TCP。勾上时协议会自动改成 TCP |

::: warning Agent 版本
基本的主备切换所有版本都支持；时段表、人工指定和探测地址要求入口机器上的 Agent 不低于 **2.2.196**；从 **2.2.197** 起每次心跳报告「现在走哪条」；评分择优、权重分配、预热预检、连续失败次数、强制断旧连接、上报评分要求 **2.2.198**。版本不够时线路面板里会写明哪些不生效。中转逐跳探测靠中转机上正常的规则探测，不要求版本。
:::

## 线路面板 {#status}

开了线路组的规则，卡片上会多一个 **「主备 · 主线路」**「定时 · 晚高峰线路」这样的标记，表示此刻走哪条。点它打开线路面板；链路管理页的 **「线路组」** 页签把所有开了线路组的规则列在一起，点「查看」进的是同一块面板。

面板从上往下：

- **现在走哪条**，以及这句话能信到什么程度（机器离线、Agent 太旧都会说明）。
- **当前路径**：每一跳的延迟和中继端口、整条路的评分和延迟 / 丢包 / 抖动 / 可用率。
- **备用路径**：各自的评分、哪条是首选、正在预热的、用不了的原因。
- **调度计划**：按什么选（此刻起作用的那一行高亮）、切换保护、预热、旧连接怎么办。
- **最近切换**：什么时候、从哪条到哪条、为什么（按时段表 / 连续探测不通 / 评分更优 / 预检未通过……）。规则开了异常提醒时，切换和计划切换未执行也发 Telegram。
- **人工指定**：临时强制走某一条（比如主线路要维护），选好时长，到点自动交回；「交回自动」提前结束。

## 高级策略 {#advanced}

「高级策略」折起来时，右边列出你改过模板值的项；全按模板时写着「按模板预填，一般不用动」。

| 分组 | 内容 |
| --- | --- |
| 切换保护 | 连续失败次数、异常多久切、恢复观察、最短驻留、恢复后切回 |
| 择优门槛（延迟优先 / 晚高峰优化） | 高出多少分、持续多久 |
| 计划切换预热（早晚高峰 / 晚高峰优化） | 提前多久，0 = 不预热 |
| 切换时旧连接怎么办 | 平滑 / 快速故障转移 / 强制 |
| 应急人工指定（自动模式下） | 强制走一条，到点自动交回；压过时段表和评分 |
| 健康检查 | 每条路径的探测地址，留空就探拨号地址 |

### 健康检查（探测地址）

Agent 默认对路径的拨号地址连一次 TCP。走中转的路径，中转到落地那段由中转机自己探；**直连落地**是 gost、realm 这类用户态转发时，连得上只说明那台机活着，给它填一个能反映整条路径的探测地址。

## 常见问题 {#faq}

### 「线路组」是灰的，勾不上

看复选框旁边那句话，常见的是：规则是**转发链**（不支持）；规则是**普通用户的普通端口转发**（点「改用隧道转发」）；隧道不是 **GOST 隧道**（换一条 GOST 隧道）。

### 保存时提示「线路组只支持 TCP」

协议选成了 UDP 或 TCP+UDP。点线路组那一块里的「改回 TCP」。

### 某条路径写着「眼下用不了」

原因就在后面：中转离线、中转没有入口地址、中转上分不出端口、落地地址没填。修好之后面板会自动重新解析（主机地址变了也会）。

### 到点没有按时段表切

依次看「最近切换」：有「计划切换未执行」就是预检没过（目标路径当时不通），面板继续走原路径；没有记录的话检查是否正处在「人工指定」里，或者 Agent 早于 2.2.196。

### 首选已经恢复了，为什么还没切回来

1. 恢复后要稳定满「恢复观察」（默认 5 分钟）；
2. 「恢复后切回首选」是否被关掉了；
3. 「最短驻留」（默认 10 分钟）还没走满；
4. 是否正处在「人工指定」或「时段表」指定的时间里。

线路面板的「调度计划」会写明此刻是哪一层在决定。
