# 全站 UI/UX 重构记录

目标：让首页、业务控制台、登录部署和使用文档遵循同一套视觉与交互规则。

## 覆盖范围

| 区域 | 调整 |
| --- | --- |
| 控制台外壳 | 导航选中态、实色顶部栏、统一页宽；功能搜索、手机底部快捷导航；手机抽屉焦点管理与 Escape 关闭 |
| 公开首页 | 定位、能力、按角色开始、常见问题四段；入口 → 链路 → 出口示意；按真实注册状态显示主行动 |
| 仪表盘 | 页面标题与真实健康状态分层，统计/账户/图表卡片共用材质；区分新工作空间、读取失败和运行正常 |
| 转发规则 | 状态与主操作、合并统计条、单行分类、移动筛选展开、可读的入口与目标地址 |
| 链路/转发组 | 标题与分类一致；路径按节点展开；显示可用、异常、待检测、已停用等实际状态 |
| 主机管理/公开监控 | Agent 维护动作收纳、搜索与分类顺序、统一统计卡和无数据提示 |
| 用户/套餐/订阅/商店 | 统一标题、统计、列表与表单层级；保留原有权限、额度、购买及续费逻辑 |
| 账单/支付/余额/计费 | 紧凑入口开关、分类导航、金额及兑换表单；财务逻辑不变 |
| 设置/通知/插件/个人资料 | 共用标题、卡片、输入与弹层；减弱装饰，提升说明文字对比度 |
| 登录/首次部署/404 | 中性画布、实色表单卡片、明确步骤、统一焦点与返回操作；登录页采用站点名称和图标 |
| 说明文档 | VitePress 接入共用令牌；导航、阅读排版、代码、提示块和翻页卡统一 |
| 通用细节 | 193 个既有表单字段的标签关联；独立字段 ID；输入触屏尺寸；错误/加载/空状态；深浅色与减少动态效果 |

## 验证方式

- TypeScript 检查覆盖生产代码与预览代码。
- Vite 应用构建、VitePress 文档构建、独立设计预览构建。
- 客户端与共享逻辑回归，增加字段标签关联的组件集成测试。
- 注册关闭/未知时不显示注册链接；手机快捷入口只使用已有可见导航；初次使用和状态异常的组件回归。
- 预览提供六个代表性视图、深浅色切换及四档视口宽度；复用生产组件，使用明确标注的示例数据。

本轮环境的自动浏览器禁止打开本地 HTML，因此尚未完成截图验收、真实触屏点击及在线业务全流程验收。发布前应在真实面板完成下列检查：

1. 320 / 390px 手机、768px 平板与 1280px 桌面；页面无横向溢出，长地址不挤压开关。
2. 分类滚动与键盘方向键；筛选展开与清除；深浅色切换、减少动态效果。
3. 新建与编辑的长弹窗；选择器、关闭与取消；重复字段标签、焦点恢复。
4. 主机、规则、链路、订阅、账单的加载/异常/空/正常状态；普通用户与管理员权限。
5. 登录、注册、首次部署、文档搜索与文档手机导航。
6. Ctrl / ⌘ K 查找功能、方向键和回车；手机“全部”抽屉、Escape、焦点恢复、虚拟键盘、安全区；权限变化后的入口可见性。

自定义 HTML 和第三方插件内部不做内容改写；它们继承共用外层，内部布局仍由用户内容决定。
