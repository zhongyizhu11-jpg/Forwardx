# 界面精致化（Quiet Precision）

> 在 V2 令牌体系之上做的一轮「质感」打磨。不改工作区的信息架构，只改**同一套令牌和
> 基础控件**，所以全站 26 个页面一起变；第 8 节照参考站重排了首页和登录页的版式。
> 规则仍以 `UI_HANDBOOK_V2.md` 为准，这份文档记录这一轮**为什么这么取值**。

## 一句话

**少一层、轻一档、准一点。**

- 少一层：侧栏不再铺白描边，卡里不再套框，表头不再铺灰，菜单高亮不再整行反黑。
- 轻一档：描边、投影、圆角、字重各退一档，让内容成为最重的东西。
- 准一点：拉丁字体随面板自带（先是 Inter，第 9 节换成 Public Sans），数字等宽，标题收字距，焦点环一种画法。

## 改了什么

### 1. 字体：Inter Variable 随面板自带（第 9 节换成了 Public Sans Variable，做法不变）

上一版字体栈把 Inter 排在系统字体后面，但面板并没有打包 Inter —— 于是 Mac 上是 SF，
Windows 上是 Segoe UI，Linux / Docker 里的浏览器是 Liberation Sans，同一个面板三种长相。

现在 `@fontsource-variable/inter` 随面板打包（按 unicode-range 分包，浏览器只下拉丁那
一份，约 100 kB），字体栈把它放在最前。中文仍交给系统（苹方 / 微软雅黑），Inter 只管
拉丁和数字。

配套打开 Inter 的几个可选字形（`cv02 cv03 cv04 cv11`：开口的 4 / 6 / 9 和单层 a），
数字在密集列表里更好认；`-webkit-font-smoothing: antialiased`；`h1–h3` 字距 -0.02em。

### 2. 中性色：近黑、更淡的线、纯中性的投影

| 令牌 | 之前 | 现在 | 为什么 |
|---|---|---|---|
| `--fx-text` | `#000000` | `#0a0a0a` | 纯黑压纯白是屏幕上最刺的一对；近黑看着仍是黑，边缘稳 |
| `--fx-text-secondary` | `#404040` | `#4a4a4a` | 主次差再拉开一点 |
| `--fx-text-muted` | `#6b6b6b` | `#707070` | 白底 4.9:1，仍过 AA |
| `--fx-l0-page` | `#f1f1f1` | `#f3f3f3` | 底稍亮一点，白卡浮得更轻 |
| `--fx-l3-control-fill` | `#f1f1f4`（偏蓝） | `#ededed` | 分段控件的槽；纯中性，且要比白卡深一档才成形 |
| `--fx-stroke-*` | `e5 / d9 / a3` | `eb / dc / a8` | 线退一档：卡片不描边之后，线只负责分隔和描边控件 |
| 投影 | 带蓝（`rgb(16 16 26)` / `rgb(24 37 54)`） | 纯黑低透明 | 偏蓝的影子在纯中性的界面上是唯一「有颜色」的东西 |

深色：页面 `#000` → `#0a0a0a`（OLED 上纯黑会把卡片边缘拖出一圈油渍），卡片 `#1a1a1a`
→ `#171717`，文字 `#fff` → `#f5f5f5`。

Tailwind 的 `--primary` / `--destructive` 原来是两个带蓝色相的 oklch 值，现在直接指向
`--fx-text` / `--fx-down`，浅深色跟着令牌走。

### 3. 圆角与高度

圆角四档各收紧一档：控件 8 / 卡片 10 / 大面 14 / 弹窗 18（之前 10 / 12 / 16 / 20）。
Tailwind 基准 `--radius` 从 0.75rem 改成 0.625rem，`rounded-sm/md/lg/xl` = 6 / 8 / 10 / 14。

新增 `--fx-elevation-control`：一层 1px 的软影，给主按钮、描边按钮、分段控件的选中块、
侧栏选中项 —— 它们要「托起半毫米」，但不需要卡片那种影子。

新增 `--fx-focus-ring`：一圈路径青 24% 的软光。全站焦点只有这一种画法，不再有
`outline: 2px solid` 加 3px 白边（白边在灰页面上像被抠出来）。

### 4. 外壳

- **侧栏**和页面同一块浅灰，不铺白、不描边、不毛玻璃。选中项是一枚**白色药丸 + 1px 软影**，
  和页面上的白卡是同一种「浮起来」的语言；深色下白卡浮不起来，退回一层浅灰。字重不加粗。
- 分组标题 11px、大写、字距 0.08em（对中文无影响，对「Workspace」这类英文有）。
- 查找框：白底、无边框、1px 软影，和选中项同一种材质。
- 底部账户块去掉边框，悬停一层浅灰。
- 「跳到主要内容」没聚焦时整个不显示 —— 它藏在视口上方，但投影会从侧栏左上角漏出来一截。

### 5. 控件

| 控件 | 现在 |
|---|---|
| 主按钮 | 反黑 + 1px 软影，悬停 88%，13.5px / 500 |
| 描边按钮 | 白底 + 基础线色描边 + 1px 软影，悬停一层浅灰，按下再深一档（`--fx-pressed`） |
| 幽灵按钮 | 无底，悬停一层浅灰 |
| 输入框 | 36px 高（手机 34），14px 字，基础线色描边，悬停线加深，聚焦路径青描边 + 焦点环，不再有内阴影 |
| 分段控件 / 分类条 | 一条比面深一档的槽、不描边；选中块白底 + 1px 软影；计数是名字后面一个淡色的数，不是胶囊 |
| 开关 | 无边框；关是基础线色的槽，开是反黑；白色滑块带一点影子 |
| 复选框 | 5px 圆角，最深档描边（20px 的空框只靠边框才看得见） |
| 徽标 | 11.5px / 500；`destructive` 改成软底深字 —— 一枚红底白字的实心徽标在一列灰字里像个警报灯 |
| 表格 | 表头不铺灰：一条细线 + 12px 灰字；行悬停是 3% 的黑 |
| 对话框 | 18px 圆角、弱线描边、`--fx-elevation-modal`；遮罩纯黑 40% + 桌面 6px 模糊（手机不模糊，会掉帧）；关闭键不再红 |
| 菜单 | 10px 圆角、4px 内边距、13px 行；高亮是一层浅灰，不是整行反黑；破坏性项高亮用故障软底 |
| 气泡提示 | 反黑、12px、无边框 |

### 6. 主机卡：卡里不再套框

「主机信息」「流量」原来各是一个描边的浅灰盒子，一张卡里三层框。现在信息区直接坐在
卡上，流量区靠一条细线和上面分开；离线只把字退到 muted，不再整块涂灰；在线点不再
常亮脉冲（脉冲只留给「正在切换」）。

## 7. 颜色：一个强调色、干净的状态色、四个分类色

上一轮之后整个面板只剩黑白灰加四个偏暗的状态色，干净但发闷。这一轮把颜色**按职责**放回去，
三组各管各的：

**强调色（薰衣草紫）只回答「这里能点 / 你在这里」。** 主按钮、开关的开、复选框的勾、侧栏和设置分区的
选中项、手机上的分类条选中块、主机分组的选中格、链接、焦点环、进度条、走势图主线 —— 全是它。
内容本身（文字、卡片、表头、分段控件）仍然是中性的，所以一屏扫过去，有颜色的地方就是能操作
的地方。三档：`--fx-accent`（字和图标，白底 5.4:1）、`--fx-accent-strong`（线、点、图表）、
`--fx-accent-fill` + `-fill-foreground`（按钮和选中块的底）。取值照一枚薰衣草色的标签来：
淡底 `#e5dff5`、字 `#8868c8`，字那一档压深到 `#6550b9`（白底 5.3:1），底是同色相的实色 `#6e56cf`
配白字（5.4:1）。深色下字提亮成 `#baa7ff`，底不变。

**状态色换成干净的绿 / 琥珀 / 红。** 原来三个都偏暗偏灰（绿发黑 `#1a8c4a`、琥珀发褐 `#b26a00`、
红发砖 `#c8362f`），一列点扫下去区分度不够。现在每档两个字色：不带后缀的是点、条、边框
（`#16a34a` / `#d97706` / `#dc2626`，要够亮才认得出），`-text` 是小字（`#15803d` / `#b45309` /
`#b91c1c`，白底 ≥ 4.5:1）。源码里直接拿状态色当小字的几处改成了 `-text`。破坏性按钮的底
单独一个 `--fx-down-fill`，深色下不跟着提亮，否则白字压浅红看不清。

**分类色四个：蓝、青、橙、粉。** 给「它是哪一种」而不是「它好不好」的标记用，刻意避开状态色
的三个色相和强调色的紫。转发工具标签原来 socat 是红、gost 是琥珀、realm 是紫 —— 一枚红标签在
一列灰字里看着像出错了；现在内核转发（iptables / nftables）走强调色，realm 蓝、gost 青、socat 橙。
交付色往品红偏（`#a21caf`），不和蓝紫的强调色认混。
`text-chart-1..9` 直接指向令牌：前五位是强调色和四个状态色（图表里的绿就是列表里的绿），
6–9 是分类色，不再是一组独立的 oklch 值。

**流量方向。** 入站走强调色，出站走次要字色（`--fx-flow-in` / `--fx-flow-out`）：进出不是
状态，只有一条需要颜色来和另一条分开。规则卡原来入站绿、出站琥珀，看着像一半的转发在报警；
现在和总览页的走势图同一对颜色。

**登录页的流动背景**从三团灰改成一团紫、一团青、再一团淡紫，都很淡；大标题第二行用强调色。

**个性化配置里的配色预设整套跟着走。** 预设原来只换 `--primary` 和 `--chart-1～4`，而且出厂写进
设置表的默认预设 `ink` 是一个反黑的主色 —— 它以内联变量盖住样式表，令牌里的强调色根本到不了
按钮上。现在 `ink` 就是「面板默认」：不写任何变量，让令牌直接生效；想要黑白的选新增的「墨色」。
其余预设（松石 / 森绿 / 紫藤 / 暖阳 / 樱粉）除了主色，还把强调色的三档一起写上，所以换成紫藤之后
按钮、开关、侧栏选中项、焦点环、路径、入站流量一起变紫；它们的 chart2～4 落到分类色的位置，
不再盖住状态色 —— 换预设换的是强调色，「正常」不该跟着染色。

## 8. 色调与布局：照参考站来

用户给了两个参考：datawave.sh 和 vexoapi.com（后者就是 New API 的前端，源码在 QuantumNous/new-api，
文档站 docs.newapi.pro 里还有一整套控制台截图）。要的是**整体色调和布局**，所以这一轮改的是底、线、
蓝、圆角和两个公开页面，不动工作区的信息架构。

**色调。** 白纸、细线、天蓝、炭灰：

| 项 | 之前 | 现在 | 照什么来 |
|---|---|---|---|
| 页面 / 卡片 | 浅灰 `#f3f3f3` 托白卡，卡不描边 | 都是 `#ffffff`，卡描一圈 `#e8e8e8` 的弱线、不投影 | 参考站 `bg-card ring-1 ring-foreground/10` |
| 侧栏 | 和页面同一块灰，选中项白药丸 | 白，右侧一条弱线；选中项淡天蓝底 + 天蓝字 | 参考站 `sidebar` / `sidebar-accent` |
| 强调色 | 薰衣草紫 `#6e56cf` | 天蓝：字和按钮 `#0b74d1`（白底 / 白字都 4.7:1），线、点、图表、渐变 `#3ea4ec`，淡底天蓝兑 14% | 参考站主色 `oklch(0.69 0.14 244)` ≈ `#3ea4ec`，白字只有 2.7:1，所以字和按钮压深一档 |
| 分类色 | 蓝 / 青 / 橙 / 粉 | 靛 `#4f46e5` / 青 / 橙 / 粉 —— 「蓝」和天蓝撞了 | 参考站图表第三色是靛 |
| 圆角 | 8 / 10 / 14 / 18 | 12 / 14 / 18 / 22，Tailwind 基准 14px | 参考站按钮 16px 压在 32px 高上、卡片 22px |
| 深色 | 近黑 `#0a0a0a` / 卡 `#171717` | 炭灰：页面 `#1e1e1e`、卡 `#2a2a2a`、弹层 `#2f2f2f`、侧栏 `#1c1c1c`，线是 10% 的白 | 参考站 `oklch(0.235 0 0)` / `0.285` / `0.305` / `0.225` |
| 登录 / 首页背景 | 三团紫 | 一团天蓝、一团青、一团淡靛 | 参考站首屏那三团光 |

「线只画一次」是这一版唯一新加的规矩：卡片描边了，卡里就不再套框；已经坐在卡片里的空状态不再描边。
EntityCard、分组列表、表格容器、摘要条、空状态各补了这一圈线，守着「不描边」的那几条测试改成守
「只有一圈弱线」。

**布局。** 两个公开页面照参考站重排，工作区的信息架构不动：

- **首页**：吸顶的毛玻璃导航（品牌在左，链接 / 主题 / 登录胶囊在右）；首屏左文右卡 —— 胶囊标签、
  第二行渐变（天蓝 → 靛 → 品红）的大标题、一段说明、一实两虚三个按钮、一排支持的转发方式；右边
  一张「终端卡」（一条规则的示意：路径三节点 + 近 24 小时的柱子 + 四个数）；背景三团淡光加一张
  64px 的网格，径向遮罩收到首屏中间。往下是数字带（3 种路径形态 / 6 种转发工具 / 24h / 1 条命令）、
  2+1 / 1+2 的功能格、三步上手（图标格 + 编号）、常见问题、收尾号召、页脚。
- **登录**：不再是左介绍右卡片的两栏。左上角一枚品牌链接回首页，页面中间一列 416px 的表单，
  标题 24px 粗体，输入框和按钮是胶囊，没有卡片（设了壁纸背景时才把卡画回来）。

**个性化预设。** 「面板默认」跟着令牌变成天蓝；上一版的薰衣草紫留成一个预设「薰衣草」，想换回去选它。

## 9. 外壳与统计块：照 Vexo 的控制台来，规格格照 kfchost

2.3.374 发出去之后用户拿手机截图来问：「让你全部借鉴，颜色和布局上也没什么改变呀？」他说得对 ——
第 8 节换的是底、线、蓝和两个公开页面，工作区本身的**形状**没动：侧栏还是 16rem 宽、里面塞着品牌、
搜索框和账户菜单；手机上还是 26px 的 iOS 大标题；统计还是「一个面、几根竖线」的摘要条。这一轮
改形状。参考站的抓取结果在项目文件 `reference-sites/`（vexoapi、kfchost 各一份 README 和 40 张截图），
Vexo 的控制台没登录看不到，它的形状照 New API 源码（`web/src/components/layout`、`dashboard`）来。

**外壳（照 Vexo / New API）。**

| 项 | 之前 | 现在 |
|---|---|---|
| 顶栏 | 没有；品牌、搜索、主题、账户都挤在侧栏里 | 一条 48px 的吸顶顶栏（`--fx-header-height`）：左边侧栏开关 + 品牌 + 版本号胶囊，右边搜索（⌘K）、主题、头像账户菜单。手机上也是这一条，搜索缩成图标 |
| 侧栏 | 16rem，白底 | 13.5rem（`--fx-sidebar-width`），从顶栏下面开始，只剩导航；菜单项 14px / 32px 高 / 10px 圆角 |
| 页面标题 | 桌面 24px；手机 26px 大标题导航栏、滚动缩进 | 桌面和手机同一形态：一行 20px（手机 18px）粗标题，主操作排在同一行右侧，下面一行 13px 说明或状态。手机每页顶上省下约 60px |
| 分段控件 | 36px 高 | 28px 高，选项圆角 `控件 - 4px` |
| 字体 | Inter Variable | Public Sans Variable（参考站量到的字体）；仍按 unicode-range 分包 |
| 圆角 | 12 / 14 / 18 / 22 | 16 / 18 / 22 / 28（参考站 `rounded-lg` 16、`rounded-xl` 22.4、`rounded-2xl` 28.8） |
| 图表色 | 天蓝、青、靛、粉、绿 | 参考站的五位：`#35a9ff` `#00a9b3` `#9095e8` `#d068d8` `#20b46b`（README 量到 `#4ca9ff` / `#00a3aa` / `#9095e8`，为了白底对比压深一点）；深色 `--fx-accent-fill` 用它的 `#0e72bc` |

**统计块（照 New API 的 StatCard）。** `SummaryStrip` 和总览页的 `SystemStatusHeader` 改成「外面一张
白卡，里面一排小格」：每格是「图标底座 + 标签」一行、下面一个等宽字体的大数（24px，手机 14px 正文
字体 —— 手机格只有 90px 宽，等宽的 `↓ 12.49 MB/s` 放不下）、再下面一行小灰字。图标底座
（`IconBadge`）是对应色兑 14% 的淡底 + 实色图标，颜色按格的顺序取图表色板，数字不正常时和数字一起
换成状态色。总览页那一块照参考站首页的 summary card 排：左「运行概况」+ 三格，右一块三团淡渐变
的「当前状态」面，写结论（运行正常 / N 处异常）和一个「查看 N 处需要关注」按钮，点了滚到下面那张
列表。手机上结论那块折到统计格上面。

**规格格（照 kfchost 套餐卡）。** kfchost 的用户中心要登录才能看，它公开页面里最像后台的是价格页：
白卡 + `#e4e4e7` 描边 + 12px 圆角，套餐卡里的规格是一排**小灰方块**（`#fafafa` 底、6px 圆角、左图标、
右边上标签下数值、两列）。手机主机卡上 CPU / 内存 / 磁盘那一行原来是一行文字「CPU — 内存 — 磁盘 —」，
现在是三个这样的方块（`--fx-l2-group` 底、8px 圆角）。它首页那种透明 header + 玻璃胶囊导航是营销页的
做法，登录按钮的紫渐变和它自己的浅蓝不一致，两样都没跟。

**数据表（照 Vexo 模型广场的表格视图）。** 抓下来量到的：一张 16px 圆角、1px `#e8e8e8` 描边、无阴影的卡包住
整张表；表头 40px、14px / 500 灰字、透明底；行 60px、1px 行线、无斑马纹、悬停极淡灰；类型 / 供应商 /
分组是**无底色的彩色文字**（蓝 `#0084cc`、青 `#00a3aa`、琥珀 `#cd8900`），不是彩底 chip；分页是一排
32px 高、16px 圆角的小按钮，当前页天蓝实底。面板的表格照着改在共用的 `ui/table.tsx` 和 `workspace.css`
里，所以转发规则、链路、用户、账单这些表一起变：表头不再是灰底粗体，行从 40px 放到 60px，表里的
Badge 一律去底去边只留字色（realm / gost / socat 的分类色留着），地址那种 `code` 不再套小框，
`PersistentPagination` 换成参考站那排小按钮、不再给整条分页描一个框。手机上仍是整卡横向滚动。

**主色控件全部改成一道天蓝渐变。** 用户在手机截图上圈了三处（「添加主机」主按钮、分段控件里选中的
「主机管理」、分类条里选中的「全部 4」），嫌饱和的皇家蓝实底太重；先改成 iOS 的 tinted 淡底，用户说
不止这三处、要的是**全部改成渐变色**。渐变取 kfchost 主按钮量到的值：`135deg rgba(140,207,255,.96) →
rgba(86,170,242,.92)`，白字，一圈 `rgba(143,194,235,.66)` 的线，下面一点同色的柔影；深色是
`#5fb0f5 → #2f86d6`。走令牌 `--fx-primary-gradient / -text / -stroke / -shadow`（`--fx-primary-fill`
是渐变的终点色，铺在渐变底下兜底），一起变的有：`Button` default、分段控件选中项（桌面手机都是）、
主机分组 chip 选中项、侧栏选中项、开关的开、复选框的勾、分页当前页、首页 journey switch。进度条和默认
徽标走的是「终点色 + 一层白色高光」（`--fx-primary-sheen`）而不是那张渐变图：它们的调用方会传状态色
（主机 CPU / 内存 / 磁盘条的绿黄红、超额的红、`--fx-healthy-soft` 这类软底徽标），不透明的渐变图会把
状态色盖掉，半透明的高光不会 —— 默认时看起来和渐变一样，染了色也还是那个颜色。白字压在浅天蓝上对比
只有 3:1 左右，靠 600 字重补 —— 这是参考站的做法，用户要的。

**毛玻璃（照 iOS 26/27 的材质）。** 只给固定不动的外壳和浮在内容上面的弹层：顶栏、手机底部
标签栏（`--fx-glass` 66% 白 + `saturate(180%) blur(20px)`），分段控件的槽（72% 灰 + `blur(12px)`），
对话框 / 手机底部 sheet / 下拉菜单 / 选择框列表（`--fx-glass-strong` 78%）。**滚动的内容本身不做
模糊**：backdrop-filter 每帧要重算它盖住的那块，盖在整页列表上就是卡顿的来源；分类 chip 只是
半透明白，不模糊。不支持 backdrop-filter 的浏览器用 `@supports not` 退回实底。

**卡顿。** 手机截图里那个「正在加载页面」是切页时的 Suspense 转圈。排下来四件事，都在这一轮改了：

| 事 | 之前 | 现在 |
|---|---|---|
| 静态资源 | 服务端不压缩、没有缓存头：入口 JS 850 kB、CSS 218 kB 每次原样下 | `compression`（gzip，1 kB 起）；`/assets` 带 hash，`immutable, max-age=1y`；`index.html` `no-cache` |
| 头像库 | `@dcasia/react-avataaars` 445 kB 随头像一起加载 | 空闲时（`requestIdleCallback`）再取，取到前画占位 |
| 动画库 | `motion.*` 把整套 framer-motion 打进入口包 | `LazyMotion` + `m.*`，功能包（`domAnimation`）走动态 import，`strict` 防止长回去 |
| 换页 | 点了才开始下那一页的代码，250ms 后转圈 | 底部标签栏按下（`pointerdown`）和侧栏悬停时先取；首屏渲染完在空闲时把常去的几页预取；`navigateAfterPrefetch` 先取代码最多等 250ms 再换页 |

入口包 850 → 787 kB（gzip 269 → 244 kB），头像库 445 kB 和动画功能包不再在首屏。真正的差别在
gzip 和缓存：第二次打开只下 `index.html` 和 API。

## 没改什么

- 工作区的信息架构和交互逻辑（首页和登录页的版式见第 8 节）。
- 状态色的**语义**（健康 / 警告 / 故障 / 待命 / 路径 / 交付）和它们出现的位置；只换了取值（见第 7 节）。
- 手机端密度层（`workspace.css` 767px 那一段）—— 只把输入框聚焦色从黑改成路径青，和桌面一致。
- 「卡片不投影」这条规矩；「不描边」在第 8 节改成了「只描一圈弱线」，守着它的测试跟着改。
