# 界面精致化（Quiet Precision）

> 在 V2 令牌体系之上做的一轮「质感」打磨。不改信息架构、不改任何一页的布局，
> 只改**同一套令牌和基础控件**，所以全站 26 个页面一起变。
> 规则仍以 `UI_HANDBOOK_V2.md` 为准，这份文档记录这一轮**为什么这么取值**。

## 一句话

**少一层、轻一档、准一点。**

- 少一层：侧栏不再铺白描边，卡里不再套框，表头不再铺灰，菜单高亮不再整行反黑。
- 轻一档：描边、投影、圆角、字重各退一档，让内容成为最重的东西。
- 准一点：Inter Variable 随面板自带，数字等宽，标题收字距，焦点环一种画法。

## 改了什么

### 1. 字体：Inter Variable 随面板自带

上一版字体栈把 Inter 排在系统字体后面，但面板并没有打包 Inter —— 于是 Mac 上是 SF，
Windows 上是 Segoe UI，Linux / Docker 里的浏览器是 Liberation Sans，同一个面板三种长相。

现在 `@fontsource-variable/inter` 随面板打包（按 unicode-range 分包，浏览器只下拉丁那
一份，约 100 kB），字体栈把它放在最前。中文仍交给系统（苹方 / 微软雅黑），Inter 只管
拉丁和数字。

配套打开 Inter 的几个可选字形（`cv02 cv03 cv04 cv11`：开口的 4 / 6 / 9 和单层 a），
数字在密集列表里更好认；`-webkit-font-smoothing: antialiased`；`h1–h3` 字距 -0.02em。

### 2. 中性色：近黑、更淡的线、纯中性的投影

| 令牌 | 之前 | 现在 | 为什么 |
|---|---|---|---|
| `--fx-text` | `#000000` | `#0a0a0a` | 纯黑压纯白是屏幕上最刺的一对；近黑看着仍是黑，边缘稳 |
| `--fx-text-secondary` | `#404040` | `#4a4a4a` | 主次差再拉开一点 |
| `--fx-text-muted` | `#6b6b6b` | `#707070` | 白底 4.9:1，仍过 AA |
| `--fx-l0-page` | `#f1f1f1` | `#f3f3f3` | 底稍亮一点，白卡浮得更轻 |
| `--fx-l3-control-fill` | `#f1f1f4`（偏蓝） | `#ededed` | 分段控件的槽；纯中性，且要比白卡深一档才成形 |
| `--fx-stroke-*` | `e5 / d9 / a3` | `eb / dc / a8` | 线退一档：卡片不描边之后，线只负责分隔和描边控件 |
| 投影 | 带蓝（`rgb(16 16 26)` / `rgb(24 37 54)`） | 纯黑低透明 | 偏蓝的影子在纯中性的界面上是唯一「有颜色」的东西 |

深色：页面 `#000` → `#0a0a0a`（OLED 上纯黑会把卡片边缘拖出一圈油渍），卡片 `#1a1a1a`
→ `#171717`，文字 `#fff` → `#f5f5f5`。

Tailwind 的 `--primary` / `--destructive` 原来是两个带蓝色相的 oklch 值，现在直接指向
`--fx-text` / `--fx-down`，浅深色跟着令牌走。

### 3. 圆角与高度

圆角四档各收紧一档：控件 8 / 卡片 10 / 大面 14 / 弹窗 18（之前 10 / 12 / 16 / 20）。
Tailwind 基准 `--radius` 从 0.75rem 改成 0.625rem，`rounded-sm/md/lg/xl` = 6 / 8 / 10 / 14。

新增 `--fx-elevation-control`：一层 1px 的软影，给主按钮、描边按钮、分段控件的选中块、
侧栏选中项 —— 它们要「托起半毫米」，但不需要卡片那种影子。

新增 `--fx-focus-ring`：一圈路径青 24% 的软光。全站焦点只有这一种画法，不再有
`outline: 2px solid` 加 3px 白边（白边在灰页面上像被抠出来）。

### 4. 外壳

- **侧栏**和页面同一块浅灰，不铺白、不描边、不毛玻璃。选中项是一枚**白色药丸 + 1px 软影**，
  和页面上的白卡是同一种「浮起来」的语言；深色下白卡浮不起来，退回一层浅灰。字重不加粗。
- 分组标题 11px、大写、字距 0.08em（对中文无影响，对「Workspace」这类英文有）。
- 查找框：白底、无边框、1px 软影，和选中项同一种材质。
- 底部账户块去掉边框，悬停一层浅灰。
- 「跳到主要内容」没聚焦时整个不显示 —— 它藏在视口上方，但投影会从侧栏左上角漏出来一截。

### 5. 控件

| 控件 | 现在 |
|---|---|
| 主按钮 | 反黑 + 1px 软影，悬停 88%，13.5px / 500 |
| 描边按钮 | 白底 + 基础线色描边 + 1px 软影，悬停一层浅灰，按下再深一档（`--fx-pressed`） |
| 幽灵按钮 | 无底，悬停一层浅灰 |
| 输入框 | 36px 高（手机 34），14px 字，基础线色描边，悬停线加深，聚焦路径青描边 + 焦点环，不再有内阴影 |
| 分段控件 / 分类条 | 一条比面深一档的槽、不描边；选中块白底 + 1px 软影；计数是名字后面一个淡色的数，不是胶囊 |
| 开关 | 无边框；关是基础线色的槽，开是反黑；白色滑块带一点影子 |
| 复选框 | 5px 圆角，最深档描边（20px 的空框只靠边框才看得见） |
| 徽标 | 11.5px / 500；`destructive` 改成软底深字 —— 一枚红底白字的实心徽标在一列灰字里像个警报灯 |
| 表格 | 表头不铺灰：一条细线 + 12px 灰字；行悬停是 3% 的黑 |
| 对话框 | 18px 圆角、弱线描边、`--fx-elevation-modal`；遮罩纯黑 40% + 桌面 6px 模糊（手机不模糊，会掉帧）；关闭键不再红 |
| 菜单 | 10px 圆角、4px 内边距、13px 行；高亮是一层浅灰，不是整行反黑；破坏性项高亮用故障软底 |
| 气泡提示 | 反黑、12px、无边框 |

### 6. 主机卡：卡里不再套框

「主机信息」「流量」原来各是一个描边的浅灰盒子，一张卡里三层框。现在信息区直接坐在
卡上，流量区靠一条细线和上面分开；离线只把字退到 muted，不再整块涂灰；在线点不再
常亮脉冲（脉冲只留给「正在切换」）。

## 7. 颜色：一个强调色、干净的状态色、四个分类色

上一轮之后整个面板只剩黑白灰加四个偏暗的状态色，干净但发闷。这一轮把颜色**按职责**放回去，
三组各管各的：

**强调色（青）只回答「这里能点 / 你在这里」。** 主按钮、开关的开、复选框的勾、侧栏和设置分区的
选中项、手机上的分类条选中块、主机分组的选中格、链接、焦点环、进度条、走势图主线 —— 全是它。
内容本身（文字、卡片、表头、分段控件）仍然是中性的，所以一屏扫过去，有颜色的地方就是能操作
的地方。三档：`--fx-accent`（字和图标，白底 5.4:1）、`--fx-accent-strong`（线、点、图表）、
`--fx-accent-fill` + `-fill-foreground`（按钮和选中块的底）。深色下字提亮到 cyan-400，
底压回 cyan-500 配近黑的字 —— 白字压亮青只有 2.5:1。

**状态色换成干净的绿 / 琥珀 / 红。** 原来三个都偏暗偏灰（绿发黑 `#1a8c4a`、琥珀发褐 `#b26a00`、
红发砖 `#c8362f`），一列点扫下去区分度不够。现在每档两个字色：不带后缀的是点、条、边框
（`#16a34a` / `#d97706` / `#dc2626`，要够亮才认得出），`-text` 是小字（`#15803d` / `#b45309` /
`#b91c1c`，白底 ≥ 4.5:1）。源码里直接拿状态色当小字的几处改成了 `-text`。破坏性按钮的底
单独一个 `--fx-down-fill`，深色下不跟着提亮，否则白字压浅红看不清。

**分类色四个：蓝、紫、橙、粉。** 给「它是哪一种」而不是「它好不好」的标记用，刻意避开状态色
的三个色相。转发工具标签原来 socat 是红、gost 是琥珀、realm 是紫 —— 一枚红标签在一列灰字里
看着像出错了；现在内核转发（iptables / nftables）走强调色，realm 蓝、gost 紫、socat 橙。
`text-chart-1..9` 直接指向令牌：前五位是强调色和四个状态色（图表里的绿就是列表里的绿），
6–9 是分类色，不再是一组独立的 oklch 值。

**流量方向。** 入站走强调色，出站走次要字色（`--fx-flow-in` / `--fx-flow-out`）：进出不是
状态，只有一条需要颜色来和另一条分开。规则卡原来入站绿、出站琥珀，看着像一半的转发在报警；
现在和总览页的走势图同一对颜色。

**登录页的流动背景**从三团灰改成一团青、一团紫、再一团淡青，都很淡；大标题第二行用强调色。

**个性化配置里的配色预设整套跟着走。** 预设原来只换 `--primary` 和 `--chart-1～4`，而且出厂写进
设置表的默认预设 `ink` 是一个反黑的主色 —— 它以内联变量盖住样式表，令牌里的强调色根本到不了
按钮上。现在 `ink` 就是「面板默认」：不写任何变量，让令牌直接生效；想要黑白的选新增的「墨色」。
其余预设（松石 / 森绿 / 紫藤 / 暖阳 / 樱粉）除了主色，还把强调色的三档一起写上，所以换成紫藤之后
按钮、开关、侧栏选中项、焦点环、路径、入站流量一起变紫；它们的 chart2～4 落到分类色的位置，
不再盖住状态色 —— 换预设换的是强调色，「正常」不该跟着染色。

## 没改什么

- 信息架构、每一页的布局、所有交互逻辑。
- 状态色的**语义**（健康 / 警告 / 故障 / 待命 / 路径 / 交付）和它们出现的位置；只换了取值（见第 7 节）。
- 手机端密度层（`workspace.css` 767px 那一段）—— 只把输入框聚焦色从黑改成路径青，和桌面一致。
- 「卡片不描边、不投影」这条规矩，以及守着它的那几条测试。
