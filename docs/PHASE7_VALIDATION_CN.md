## 本轮改动

- 增加 `pnpm test:all`，自动发现 server、shared、client/src、scripts 下的测试；
  CI 改用此入口。原默认命令漏掉的 8 个已有测试文件也会执行，原专项命令仍保留。
- 修复 setupFlow 测试依赖非回环网卡的问题：仅在独立测试进程中模拟迁移 HTTP 响应，
  仍经过真实 URL 校验、setup 路由、迁移任务及 SQLite。核对请求地址、方法和迁移码，
  等到迁移请求发出后创建管理员，验证迁移完成前 setup 不会提前关闭。
  没有跳过测试，也没有放宽生产环境的地址校验。
- 主机与链路分类在窄屏自动换行，去掉滑动彩色底块，选中状态改用字重和文字颜色。
- 补充视图选择、链路同步/编辑/删除、隧道编辑/删除及移除成员按钮的无障碍名称；
  视图选择暴露选中状态，链路同步请求未完成时禁止重复提交。
- 所有 `size="icon"` 按钮明确标记，使触屏 CSS 能覆盖默认 40px 图标按钮。
  触屏卡片操作区保留 8px 间距并允许换行；订阅自动续费标签增加触控高度和明确名称。
