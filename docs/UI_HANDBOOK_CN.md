# ForwardX 界面规范

本文是 UI 重构阶段的**唯一依据**，摘自指定的参考手册
（[形色场 UI Handbook](https://uihandbook.zzhzhou2026.workers.dev/)），
并映射到本项目已有的 Tailwind v4 令牌上。

写新界面、改旧界面之前先读这里；和本文冲突的写法一律以本文为准。

---

## 零、先读这一条

手册自己的立场是：**全部采用克制的黑白灰实现**，强调色只出现在
主按钮、链接、焦点环、选中态 —— 「出现越少越有力量」。

所以本文列出的毛玻璃、光束、流动渐变**不是可以随便撒的装饰**。
它们每一个在手册里都自带使用边界和性能警告，抄效果不抄边界等于没读。
每一节末尾的「什么时候不要用」和「代价」跟效果本身同等重要。

本项目原则不变：**高级感来自信息层级、留白、排版，动效只做克制的补充。**
这和手册不矛盾 —— 手册本身就是一套黑白灰的克制系统。

## 一、令牌

项目已有的 `client/src/index.css` 用 `@theme inline` + 语义变量
（`--background` / `--foreground` / `--border` / `--ring` …），
这正是手册要求的做法：**定义语义色，不要直接写色值，深色模式只换变量**。
新增颜色一律走变量，不要在组件里写 `zinc-700` 这类字面量。

### 字号

倍率比例（1.25 Major Third）：

```
12 / 14 / 16 / 20 / 24 / 32 / 40 / 48
```

- 所有数字（表格、计时、金额、流量）必须 `tabular-nums`，防止宽度跳动。
- 大数字：`text-2xl font-semibold tabular-nums`。
- 图标大小 = 字号；图标与文字间距 8px。

### 圆角

- **同一界面圆角不超过 3 种。**
- 嵌套公式：外层 `rounded-2xl`(16) + `p-2`(8) → 内层 `rounded-lg`(8)。
- 状态徽章 `rounded-full`；可移除标签 `rounded-md`（更像「对象」）。
- 卡片默认：圆角 12px（`rounded-xl`），内边距 20px（`p-5`）。

### 层级与阴影

| 层 | 浅色 | 深色 |
| --- | --- | --- |
| 页面 | `white` | `zinc-950` |
| 卡片 | `white` | `zinc-900` |
| 悬浮层 | `white` + 边框 | `zinc-900` + 边框 |

- 边框：浅色 `200`，深色 `800`；**分割线比边框再淡一级**。
- 阴影颜色**不要用纯黑**，用 `rgb(0 0 0 / 0.06 ~ 0.12)`。
- 多层阴影公式：
  `0 1px 2px rgba(0,0,0,.04), 0 4px 12px rgba(0,0,0,.06), 0 12px 32px rgba(0,0,0,.08)`
- **深色模式阴影几乎不可见 —— 改用更亮的边框表示层级**，不要只是简单反色。
- 避免纯黑 `#000` 做大面积背景，用 `zinc-950`。

### 间距

- 优先 `gap`（flex / grid），不要 `margin` —— 避免外边距折叠和末元素多余间距。
- **留白宁多勿少**，它是极简风格的骨架。

## 二、动效

### 三档时长

| 档 | 时长 | 用于 |
| --- | --- | --- |
| 快 | **150ms** | hover / 按下 / 颜色变化 |
| 中 | **200–300ms** | 菜单、弹窗进入 |
| 慢 | **400–500ms** | 页面转场 |

- **退出时长 = 进入 × 0.8**（进入 250ms → 退出 200ms）。
- 缓动：进入 `ease-out`（快出慢停）、退出 `ease-in`、
  弹性用 `cubic-bezier(0.32, 0.72, 0, 1)`。

### 铁律

1. **只对 `transform` 和 `opacity` 做动画** —— 不触发重排，GPU 加速。
2. **尊重 `prefers-reduced-motion: reduce`**，把时长压到接近 0。
3. 超过 5 秒的循环动画**必须提供暂停方式**（WCAG 2.2.2）。
4. 动画要有物理感：进入从下向上 8–12px + 淡入；退出反向且更快。
5. 列表出现用 stagger，每项延迟 **30–50ms**（滚动进场可到 80ms）。

### 具体场景

- 弹窗 / 菜单：`200ms ease-out` + `scale 0.96→1`。
- 下拉菜单：`origin-top-left` + `scale 0.96→1` + 淡入，**180ms**。
- 抽屉 / 底部面板：`300ms cubic-bezier(0.32,0.72,0,1)`。
- Switch 滑块：`translate-x` 过渡 **200ms**，轨道颜色同步。
- 按下：`active:scale-[0.98]`，或去掉阴影。
- hover 只在支持的设备生效：`@media (hover: hover)`。
- **加载超过 300ms 才显示 loading**，避免闪烁。
- 两段式移除：先标记 `leaving` 触发退出动画，300ms 后真正删除。

### auto 高度动画

外层 `grid` + `gridTemplateRows: open ? '1fr' : '0fr'`，内层 `overflow-hidden`。
手册称这是目前最优雅的方案。

## 三、用户点名的几个效果

### 毛玻璃

```
浅色：bg-white/80  backdrop-blur  border-b
深色：bg-zinc-900/50  border-white/10
遮罩：fixed inset-0 bg-black/40 + backdrop-blur-md
```

**代价（手册明写）**：`backdrop-filter` 开销大，
**避免大面积和滚动中频繁重绘**。Safari 需要 `-webkit-backdrop-filter`（Tailwind 已处理）。

用在：粘性头部、模态遮罩、悬浮面板。不要整页铺。

### 边框光束

**不要用 conic-gradient。** 手册明确把那个列为「旧方案」，因为那是渐变。

现代做法：一个光点沿容器圆角矩形路径走 ——

```css
offset-path: rect(0 100% 100% 0 round 12px);
/* 光点用 box-shadow 发光 */
```

用在：AI 生成中、长任务进行中的状态框。不要当常驻装饰。

### 流动渐变背景

4 个 `rounded-full` 圆 + `blur-3xl`（大半径高斯模糊），不同位置互相叠出渐变。

- 复用 `animate-float` 上下浮动，**用负 `animation-delay` 错开相位** ——
  产生「流动」而不是「同频呼吸」。
- **颜色克制**：浅色下 `zinc-200~500` 低透明度，深色下 `zinc-500~800`，
  保持黑白灰基调。
- 移动端性能：大区域 `blur-3xl` 有开销，可降级为普通 `radial-gradient`。
- `prefers-reduced-motion` 下退化为静态渐变。

用在：需要「科技感」但不想上彩色渐变的场合（登录页、空状态）。
**工具型页面（列表、表单、详情）不要用。**

### 进度条

- **不确定时长用不确定进度（滑动条），不要假进度。**
- 上传进度用 `XHR.upload.onprogress` 或 `fetch` + `ReadableStream`。
- 阅读进度可用 CSS `animation-timeline: scroll()` 零 JS 实现。
- 剩余秒数 `tabular-nums`，数字变化时宽度不抖。

## 四、组件

### 卡片

- 圆角 12px，内边距 20px。
- **不要把卡片套卡片。**
- 可点击卡片：`hover:-translate-y-0.5 hover:shadow-md`，
  箭头 `group-hover:translate-x-1`。
- 整卡可点击用 `<a>` 包裹，或卡片内放覆盖全卡的伪元素链接。
- 媒体卡片用 `overflow-hidden` 让图片跟随圆角。
- **Radio Card 选中态用 `ring-1` + 边框同色，不要加粗边框** —— 会导致布局跳动。
- 移动端表格转为卡片列表。

### 开关 Switch

- 用于「切换后立即生效、无需提交」的设置项。需要提交的用 Checkbox。
- 滑块 `translate-x` 过渡 200ms，轨道颜色同步。
- 空格键切换。

### 复选框

- 多选场景用 Checkbox 列表；选项超过 6 个改用 Select 更省空间。
- 空格键切换。

### 焦点态（全站统一）

- 用 `:focus-visible` 而不是 `:focus` —— 鼠标点击不出现焦点环。
- 焦点环：**2px + 2px 偏移**。
- 表单柔和焦点态：`focus:ring-4 ring-zinc-900/10 + focus:border-zinc-900`
  （本项目用 `ring` 变量）。

### 表单

- `label` 用 `htmlFor` 关联，帮助文字用 `aria-describedby` 关联。
- **错误信息替换帮助文字，不要叠加。**
- 错误态：`border-red-500` + `aria-invalid` + 红色文字 + 图标。
- **实时校验**，不要等提交才报错。
- 到达边界时 `disabled` 对应按钮，而不是点了没反应。

### 按钮

- **不要用 `div` 模拟按钮** —— 原生 `<button>` 天然支持键盘与焦点。
- 图标按钮必须有 `aria-label`。
- 危险操作在菜单内用红色 + hover 红底；确认框的危险按钮**不要默认聚焦**。

### 无障碍底线

- 正文对比度 ≥ 4.5:1，大字与图标 ≥ 3:1（WCAG AA）。
- Tab 顺序 = DOM 顺序，**不要用 `tabindex > 0`**；
  复杂组件内部用 roving tabindex。
- Enter 激活按钮，空格切换开关 / 复选，方向键移动单选组与菜单。
