# ForwardX 界面规范

UI 重构阶段的**唯一依据**。

来源：[形色场 UI Handbook](https://github.com/zzhzhouzhou/UI-handbook)
（作者 zzh_zhou · Garbage Human Studio）。本文取自该仓库的官方离线规范
`docs/handbook.md` 与组件源码 `src/`，并映射到本项目已有的 Tailwind v4 令牌。

写新界面、改旧界面之前先读这里；和本文冲突的写法一律以本文为准。

---

## 零、三条前提

手册开篇原话：**一套界面看起来是否「高级」，取决于底层规范是否统一，
而不是某个组件做得多漂亮。**

1. **克制用色** —— 绝大部分面积是黑白灰，彩色只留给最重要的动作和信息。
   「一个页面里强调色出现得越少，它就越有力量。」
2. **一切尺寸有出处** —— 字号、间距、圆角、高度都从下面的表里取值，不许随手填。
3. **照顾所有人** —— 对比度达标、可点面积够大、键盘能用、尊重「减少动态效果」。

> **装饰性动效要克制：一个页面最多一两处。**
> 这句是手册自己写的。毛玻璃、边框光束、流动渐变都归这一类 ——
> 它们是**点缀**，不是底色。

## 一、颜色

一套界面只需要三种颜色：

| 类别 | 占比 | 用途 |
| --- | --- | --- |
| 中性灰阶 | **约 90%** | 背景、卡片、文字、分割线，承担全部结构 |
| 强调色 | **约 10%** | 只用于最重要的动作和信息 |
| 语义色 | 少量 | 成功绿 / 警告黄 / 错误红 / 信息蓝 |

### 灰阶怎么用

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 页面背景 | 最浅一级（近白） | 最深一级（**近黑，不是纯黑**） |
| 卡片背景 | 白 | 比页面背景**略亮** |
| 分割线 | 比背景略深一级 | 比背景略亮一级 |
| 次要文字 | 中灰 | 中灰偏亮 |
| 主要文字 | 近黑（**不是纯黑**） | 近白（**不是纯白**） |

- **深色模式不是简单反色**：背景不用纯黑、文字不用纯白，层级越高背景越亮。
- **阴影在深色模式下几乎看不见，改用「稍亮的边框」表达层级。**

本项目已有 `client/src/index.css` 的 `@theme inline` + 语义变量
（`--background` / `--foreground` / `--border` / `--ring` …），
这正是手册要求的做法。**新增颜色一律走变量**，不要在组件里写 `zinc-700` 这类字面量。

### 对比度（硬性）

| 内容 | 最低亮度差 |
| --- | --- |
| 正文小字 | **4.5 : 1** |
| 大字（约 24px 以上） | 3 : 1 |
| 图标、边框、开关等控件 | 3 : 1 |
| 正文加强版 | 7 : 1 |

- **深浅模式分别检查**，浅色达标不代表深色达标。
- **不能只靠颜色传达信息** —— 错误状态必须同时有图标或文字。

## 二、文字

### 字号与行高（成对出现，不许单独调）

| 层级 | 字号 | 行高 | 用途 |
| --- | --- | --- | --- |
| 特大标题 | 48px | 1.1 | 落地页主标题 |
| 一级标题 | 32px | 1.25 | 页面标题 |
| 二级标题 | 24px | 1.33 | 区块标题 |
| 三级标题 | 20px | 1.4 | 卡片标题 |
| 正文 | 16px | 1.6 – 1.75 | 普通内容 |
| 辅助说明 | 12px | 1.5 | 时间、备注 |

标题字距略收紧，正文默认。

### 排版规则

- **中文正文每行 30–40 字**，太长眼睛累。
- **所有数字用等宽数字**（`tabular-nums`）—— 金额、时间、流量、表格。
  否则数字变化时左右跳动。
- **中文不要用斜体** —— 中文没有真正的斜体，强行倾斜只显得廉价。
- **强调用加粗或变色，不要用下划线**（容易被误认为链接）。

## 三、间距

**只允许 4 的倍数**：`4 · 8 · 12 · 16 · 24 · 32 · 48 · 64`（px）

| 场景 | 间距 |
| --- | --- |
| 组件内部（文字与边框之间） | 4 – 12px |
| 组件与组件之间 | 16 – 24px |
| 区块与区块之间 | 48 – 96px |

**间距的远近代表关系的远近**：相关的靠近，无关的拉开。

- 优先 `gap`（flex / grid），不要 `margin` —— 避免外边距折叠和末元素多余间距。
- 页面内容限最大宽度：阅读类约 672px，应用类约 **1152px**，左右留白居中。

## 四、尺寸与圆角

### 高度

| 元素 | 高度 |
| --- | --- |
| 密集工具栏按钮 | 32px |
| 常规按钮 / 输入框 | 36px |
| 主要按钮 / 大按钮 | 44px |

### 触控目标（硬性）

**任何可点的东西，实际可点面积不能小于 44×44px。**

- 图标画 16–24px 没问题，但**要在周围补透明区域把可点面积撑到 44px**。
- **相邻可点元素之间至少 8px 空隙**，防误触。

### 图标与头像

- 图标：16 / 20 / 24px（行内 / 按钮 / 大图）
- 头像：24 / 32 / 40 / 56px

### 圆角

| 元素 | 圆角 |
| --- | --- |
| 小元素（开关、小按钮） | 6px |
| 卡片 | 12px |
| 弹窗 | 16px |

- **一个界面圆角不超过三种。**
- 嵌套公式：**内层圆角 = 外层圆角 − 两者之间的间距**。
  （外 `rounded-2xl`(16) + `p-2`(8) → 内 `rounded-lg`(8)）

## 五、阴影与层级

- 阴影要**几乎看不见**：多层极淡的黑叠加，不是一坨深色。
  `0 1px 2px rgba(0,0,0,.04), 0 4px 12px rgba(0,0,0,.06), 0 12px 32px rgba(0,0,0,.08)`
- **阴影颜色不用纯黑**，用 `rgb(0 0 0 / 0.06 ~ 0.12)`。
- 层级越高阴影越明显：卡片几乎无阴影，弹窗最重。
- 深色模式改用边框亮度区分层级。

### z-index 全站只有这 6 档

| 层级 | 值 | 元素 |
| --- | --- | --- |
| 页面内容 | 0 | 普通内容 |
| 悬浮卡片 | 10 | hover 浮起的卡片 |
| 下拉菜单、气泡 | 20 | 弹出菜单 |
| 粘性头部、侧边栏 | 40 | 吸顶导航 |
| 遮罩 + 弹窗 | 50 | 半透明黑底 + 对话框 |
| 全局提示 Toast | 60 | 永远在最上 |

**用变量统一管理，禁止随手写大数字。**
半透明遮罩出现时，比它层级低的内容都不应该可以点击。

## 六、动效

### 时长

| 场景 | 时长 |
| --- | --- |
| 悬停、按下、变色 | **150ms** |
| 菜单、弹窗出现 | **200 – 300ms** |
| 退出 | **比进入快 20%** |
| 页面转场 | 400 – 500ms |

缓动：进入 `ease-out`（快出慢停）、退出 `ease-in`、
弹性 `cubic-bezier(0.32, 0.72, 0, 1)`。

### 规则

1. **只对位置、大小、透明度做动画**（`transform` / `opacity`），不触发重排。
2. 出现先快后慢，退出更快，界面才有干脆感。
3. **尊重「减少动态效果」** —— 用户关闭时立即呈现最终状态。
4. **装饰性动效一个页面最多一两处。**
5. 列表出现用 stagger，每项延迟 30–50ms。
6. **加载超过 300ms 才显示加载动画**，避免一闪而过。
7. 超过 5 秒的循环动画必须能暂停（WCAG 2.2.2）。

### 手册的 keyframes（可直接搬）

```css
@keyframes beam  { from { offset-distance: 0% }   to { offset-distance: 100% } }
@keyframes float { 0%,100% { transform: translateY(0) } 50% { transform: translateY(-8px) } }
@keyframes fadeUp   { from { opacity:0; transform: translateY(12px) } to { opacity:1; transform:none } }
@keyframes scaleIn  { from { opacity:0; transform: scale(.96) }       to { opacity:1; transform:none } }
```

```
--animate-beam:     beam 4s linear infinite;
--animate-float:    float 4s ease-in-out infinite;
--animate-fade-up:  fadeUp .5s ease-out both;
--animate-scale-in: scaleIn .18s ease-out both;
--animate-slide-up: slideUp .28s cubic-bezier(.32,.72,0,1) both;
```

### auto 高度动画

外层 `grid` + `gridTemplateRows: open ? '1fr' : '0fr'`，内层 `overflow-hidden`。
手册称这是目前最优雅的方案。

## 七、点名的几个效果（照抄手册源码）

### 毛玻璃

```html
<div class="rounded-2xl border border-white/60 bg-white/50 p-5 shadow-xl
            backdrop-blur-xl backdrop-saturate-150
            dark:border-white/10 dark:bg-zinc-900/50">
```

- 用于：粘性导航栏、播放器控制条、地图信息卡、模态遮罩。
- **下方必须有内容（形状 / 图片）才有意义** —— 纯色底上做毛玻璃等于没做。
- **代价**：`backdrop-filter` 开销大，**避免大面积和滚动中频繁重绘**。

### 边框光束

**不要用 conic-gradient。** 手册明确把「conic-gradient 旋转 + mask 只留边框」
列为旧方案，理由是「那是渐变」。

```html
<span class="absolute h-2 w-2 rounded-full bg-zinc-900
             shadow-[0_0_12px_2px_rgb(24_24_27/0.6)]
             dark:bg-white dark:shadow-[0_0_12px_2px_rgb(255_255_255/0.8)]"
      style="offset-path: rect(0 100% 100% 0 round 12px);
             animation: beam 4s linear infinite"></span>
```

包在 `pointer-events-none absolute inset-0 rounded-xl` 的层里。
纯 CSS，零 JS，零渐变。

- 用于：**强调「正在进行」的卡片**（下发中、检测中、生成中）。
- 不做常驻装饰。

### 流动渐变背景

```html
<div class="relative overflow-hidden">
  <div class="absolute inset-0 bg-zinc-50 dark:bg-zinc-950"></div>
  <div class="absolute -left-10 -top-10 h-52 w-52 animate-float rounded-full bg-zinc-300/80 blur-3xl"></div>
  <div class="absolute -right-8 top-6 h-44 w-44 animate-float rounded-full bg-zinc-400/70 blur-3xl"
       style="animation-delay:-1.2s"></div>
  <div class="absolute bottom-0 left-1/4 h-48 w-48 animate-float rounded-full bg-zinc-200 blur-3xl"
       style="animation-delay:-2.4s"></div>
</div>
```

- **负 `animation-delay` 错开相位** —— 产生「流动」而不是「同频呼吸」。这是关键。
- **颜色克制**：浅色 `zinc-200~500` 低透明度，深色 `zinc-500~800`。
- 移动端大区域 `blur-3xl` 有开销，可降级为 `radial-gradient`。
- `prefers-reduced-motion` 下退化为静态渐变。
- 用于：登录页、Hero、空状态卡片。**列表 / 表单 / 详情这类工具型页面不用。**

### 进度条

- **不确定时长用不确定进度（滑动条），不要假进度。**
- 剩余秒数 `tabular-nums`，数字变化时宽度不抖。

## 八、组件规则

### 按钮

- **一个页面里「主要按钮」只出现一次**，其余用次要 / 描边。
- 按下 `active:scale-[0.98]`；加载中禁止重复点击并显示转圈。
- 危险操作用红色，**必须二次确认**；确认框的危险按钮**不要默认聚焦**。
- **不要用 `div` 模拟按钮**，原生 `<button>` 天然支持键盘与焦点。
- 图标按钮必须有 `aria-label`。

### 输入

- 四部分：**标签、输入区、帮助文字、错误提示**。标签永远在上方。
- **错误提示替换帮助文字，不要叠加**；红字 + 图标，随输入实时更新。
- 密码框必须有「显示 / 隐藏」；强度反馈在输入时给，不是提交后。
- 选项 4–10 个用下拉；超过 10 个或需要搜索用可输入下拉。
- 焦点用 `:focus-visible` 不是 `:focus`；焦点环 2px + 2px 偏移。

### 卡片

- 圆角 12px，内边距 20px。**不要把卡片套卡片。**
- 可点击卡片：`hover:-translate-y-0.5 hover:shadow-md`。
- **Radio Card 选中态用 `ring-1` + 边框同色，不要加粗边框** —— 会导致布局跳动。

### 开关 / 复选框

- **Switch 用于「切换后立即生效、无需提交」**；需要提交的用 Checkbox。
- 滑块 `translate-x` 过渡 200ms，轨道颜色同步。
- 空格键切换。

### 导航

- 当前位置用**颜色和字重**区分，**不加彩色高亮块**。
- 层级超过四层用面包屑；步骤少于六个用步骤条。
- 移动端底部导航入口不超过 5 个。

### 反馈

- 成功轻提示 3 秒左右自动消失；**错误提示要等用户处理**。
- 列表为空时给出解释和下一步动作，**不要留白**。
- 弹窗打开时背景页面不能滚动；Esc 能关闭。

### 数据展示

- **数字右对齐 + 等宽；文字左对齐。**
- **表格去掉竖线**，只保留极淡的横向分隔。
- 空数据显示空状态（图标 + 说明 + 行动按钮）。

## 九、响应式

| 名称 | 宽度 |
| --- | --- |
| 手机 | < 640px |
| 平板竖屏 | ≥ 640px |
| 平板横屏 | ≥ 768px |
| 笔记本 | ≥ 1024px |
| 桌面 | ≥ 1280px |

**从手机开始设计**，先保证小屏可用再向大屏增强。

| 桌面 | 手机 |
| --- | --- |
| 多列表格 | 卡片列表 |
| 侧边栏 | 抽屉 / 底部导航 |
| 居中弹窗 | 底部面板 |
| 悬停展开 | 点击展开 |

**底线**：320px 宽不允许左右滚动；触屏没有悬停，所有悬停效果必须有点按替代。

## 十、上线走查清单

**层级**
- [ ] 页面只有一个一级标题，标题层级不跳级
- [ ] 主按钮每屏只出现一次
- [ ] 重要信息在视线上方

**一致性**
- [ ] 同类元素的尺寸、圆角、间距完全一致
- [ ] 图标风格统一（全线性或全面性）
- [ ] 按钮文案用动词，语气一致

**反馈**
- [ ] 所有操作 100ms 内有视觉反馈
- [ ] 异步操作有加载态，完成后有结果提示
- [ ] 错误信息说明原因和解决方式

**无障碍**
- [ ] 对比度 ≥ 4.5:1，且不仅靠颜色传达信息
- [ ] 键盘可完成全部操作，焦点清晰可见
- [ ] 图标按钮有文字说明

**响应式**
- [ ] 320px 宽度下不出现左右滚动
- [ ] 触控目标 ≥ 44×44px
- [ ] 悬停效果在触屏上有替代方案

**性能**
- [ ] 动画只使用位移和透明度
- [ ] 图片懒加载且尺寸固定
- [ ] 首屏无布局跳动

## 十一、本项目的文案规则（不来自手册）

短、准、专业。「已保存」，不是「您的操作已经成功完成」。

### 操作结果提示用「已 X」，不用「X 成功」

全站量过：**「已 X」式 168 处，「X 成功」式 13 处** —— 房规就是「已 X」，
少数派是漏网的。

```
主机已更新     不是  主机更新成功
密码已修改     不是  密码修改成功
规则已创建     不是  规则创建成功
已支付         不是  支付成功！
```

三类例外，不要机械替换：

1. **状态机标签**。升级任务那一组是「正在升级 / 升级成功 / 升级出现异常」，
   三个状态成组出现，单独把中间那个改成「已升级」会破坏对仗。
2. **语义会变的**。「注册成功」不能改成「已注册」—— 后者读起来像
   「这个账号早就注册过了」，是个错误提示。
3. **本来就不是成功提示**。「部分成功」「动作执行未成功」。

### toast 句尾不加标点

量过：**476 条不带，8 条带句号**。不带是房规。
句子再长也不加 —— toast 是一句话，不是一段话。

### 必填字段一律标星号

标了「选填」就必须真的能不填。前车之鉴：本项目曾把「规则名称」标成选填，
而创建按钮的禁用条件里恰恰有 `!form.name` —— 用户照着标签留空，
只会得到一个灰按钮和零解释，比不标更糟。
